About UIDAI CBT Mock Test

This fully offline exam portal is built with pure HTML5, CSS3 and vanilla JavaScript. It reads a structured JSON question bank and delivers a premium CBT experience without servers.

Features

  • Complete offline use from index.html.
  • Smart test settings with question count, topic selection, and shuffle options.
  • Automatic saving and resume from browser storage.
  • Result analytics, performance dashboard and review mode.
  • Bookmarking, note taking and keyboard navigation.
  • Import new question sets using JSON input.

How it works

The app loads data/questions.json locally, builds randomized quizzes, tracks answers, and saves progress in localStorage. You can open this project directly from your browser.

Designed for UIDAI exam preparation and realistic CBT practice.
